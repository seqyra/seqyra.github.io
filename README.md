## 🇬🇧 English

### 💗 about me

hi! i'm **seqyra** — a pink enjoyer, gamer and professional headpat receiver.
i live somewhere between falling sakura petals and my steam library.
this repo is my little corner of the internet: a pastel bio site with a very
pettable cat, a petal-catching mini-game and way too many hearts. welcome ♡

### 🌸 what's inside

| | |
|---|---|
| 🎀 | pastel pink anime design with floating polaroids & falling sakura |
| 🐾 | cat-paw cursor that leaves little walking paw prints |
| 💗 | **headpats** — click the character, milestones at 1 / 10 / 25 / 50 / 100 |
| 🎮 | **petal game** — 30 seconds, catch petals with your paw, gold = ×3, best score saved |
| 😴 | the corner neko **falls asleep** after ~45s of idle (wake it gently…) |
| 🎵 | tiny kawaii music-box melody, generated live in the browser |
| 👁 | **all-time visitor counter** — works on GitHub Pages, no backend |
| 🎊 | sakura burst on double-click · heart storm on **N** · a pink button you should NOT boop |

### 🚀 run & deploy

```
just open index.html — that's it. no build, no dependencies.
```

deploy free on **GitHub Pages**: push this folder to a repo → Settings → Pages →
deploy from branch `main`, folder `/ (root)`. done ♡

### 🔗 links

all links are already wired up (TikTok, Telegram, Steam, Tonkeeper) —
except **GitHub**: open `index.html`, search for `INSERT` and paste your profile URL.

### 👁 visitor counter

the footer counts all-time visits via the free [Abacus](https://abacus.jasoncameron.dev) API —
static-host friendly, one `fetch`, no signup. **before deploying**, open `script.js` and change
`COUNTER_NAMESPACE` to something unique to you (e.g. `seqyra-github-io-2026`).
if the API is unreachable, the counter politely shows `♡`.

### 🖥 console spells

```js
seqyra.nya()        // heart storm
seqyra.sakura()     // sakura burst
seqyra.hearts(60)   // MORE hearts
seqyra.headpat(10)  // automated affection
seqyra.bgm()        // secret music mute/unmute
seqyra.game()       // start the petal game
```
